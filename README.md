# VECTRA
A modern, dark-navy SaaS startup website for VECTRA featuring glassmorphism UI, interactive product/service filtering, smooth animations, and responsive design.
VECTRA — Turning Innovative Ideas Into RealityA modern, visually striking, and fully responsive SaaS & technology startup website built for VECTRA (Vectra Systems). Designed with a dark-navy, electric-blue, and violet-purple aesthetic, the site combines glassmorphism surfaces, custom geometric SVG illustrations, scroll-reveal animations, and interactive product/service exploration inside a lightweight single-file architecture.✨ Key FeaturesPremium Dark-Navy SaaS Aesthetic: Crafted with a deep navy palette (#070B19 / #0B1021), electric blue (#3B82F6), and purple (#8B5CF6) gradients paired with subtle grid textures and glassmorphic cards.Sticky Glassmorphic Navigation Bar: Responsive header with custom VECTRA geometric logo, section navigation links, a highlighted Get Started CTA, and an accessible mobile drawer menu.Dynamic Hero Section:Bold value proposition ("Turning Innovative Ideas Into Reality") and dual CTAs.Animated abstract 3D-inspired isometric cube & orbital telemetry console built with crisp inline SVGs.Key startup metrics (240+ Projects Completed, 98% Happy Clients, 6+ Years of Innovation).Company Introduction ("Who We Are"): Startup origin story, vector studio illustration, Vision & Mission callouts, 5 Core Values, and 2026–2027 strategic roadmap goals.Interactive "What We Build" Showcase:Live category filter tabs (All Offerings, Flagship Products, Engineering Services).Interactive Architecture / Engagement Scope Modal that lets visitors inspect capabilities and auto-selects the chosen solution in the contact form.Achievements, Team & Testimonials: Milestone timeline, key performance metrics, leadership profiles, and client social proof.Validated Demo & Consultation Form: Client-side validation with accessible inline feedback banners—zero browser alert() popups.Zero Build-Step Architecture: Self-contained single HTML file powered by Tailwind CSS (CDN), Google Fonts (Plus Jakarta Sans & Inter), and vanilla ES6+ JavaScript.🛠️ Tech StackLayerTechnologyMarkupSemantic HTML5StylingTailwind CSS (via CDN) + Custom CSS Glassmorphism & Keyframe AnimationsTypographyGoogle Fonts (Plus Jakarta Sans for headings, Inter for body)InteractivityVanilla JavaScript (IntersectionObserver, DOM filtering, modal state, form validation)GraphicsCustom inline scalable vector graphics (SVGs)📂 Project
